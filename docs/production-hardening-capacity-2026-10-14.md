## Remaining verification, with closure criteria
1. **Authenticated live hosted encryption workflow** — New job via approved operator browser, actual model, encrypted delivery to the same approved device; review signer, execute, save locally/cloud, reload and reopen. Keep any unrelated signed device vault intact. Do not claim end-to-end completion from separate stored-package/import proofs.
2. **Device coverage** — Check Android Chrome and iOS Safari on booted simulators, plus a real Android handset and real iPhone; verify keyboard/touch, screen-reader/navigation, offline reopen, fresh install, upgrade/restore and permissions. Simulator success is not physical-device evidence.
3. **Representative scale and resilience** — Test local production replica under bounded concurrent sign-ins, document reads, saves, retries, service/database failures and worker lease restarts; record throughput, p50/p95/p99 and recovery, with data and backups isolated. Avoid hammering single Render Free instance as a surrogate for real capacity.
4. **Off-device operations** — Verify actual daily backup job and completed restore, alert delivery on deliberate staging failure, quota exhaustion alert, generation failure, DB outage, mail failures, scheduled worker liveness, retry cadence, recovery time objectives. Alert delivery not proven by a green happy-path cron run.
5. **Final launch audit** — Review threats and controls for auth/session boundaries, E2EE, vault key recovery, signer trust, authenticated Caddy edge, RBAC, data retention/deletion, migrations, support, billing refunds, artifact provenance, exact Git SHA. Production scope/limits must match product copy.

## AI inference capacity and alternatives
- Cloudflare official free allocation (2026-10-01 documentation): **10,000 neurons per UTC day**, with free requests hard-failing after exhaustion. Needware purposefully keeps **8,000 shared daily internal quota** and **4,000 per account**, two concurrent jobs. The 2,000 buffer protects against retries, other account use and unknown usage; do NOT increase simply by changing a number. <https://developers.cloudflare.com/workers-ai/platform/pricing/>
- Current Cloudflare model @cf/openai/gpt-oss-120b charges the equivalent of $0.35 / million input tokens, $0.75 / million output tokens. Cloudflare Workers Paid costs $5/month, while per-neuron inference above the daily free allowance is $0.011 per 1,000 neurons at time of research. At 924 neurons (max reserved job) **variable overage ~US$0.01016 per worst-case job**, excluding plan base, taxes, FX, other services and any changes in provider fees. At measured 216.33 neurons, variable overage would be ~$0.00238 per job. The customer-facing INR prices do not make actual hosted inference unlimited. <https://developers.cloudflare.com/workers-ai/models/gpt-oss-120b/> <https://developers.cloudflare.com/workers-ai/platform/pricing/>
- Groq free GPT-OSS-120B as published: 30 RPM, 1,000 RPD, **8,000 tokens per minute** and 200,000 tokens per day, at the organization level. A multi-stage request with a large application schema can exceed minute throughput. It is not a safely qualified automatic fallback: implement compact prompt/schema and run raw-output/native-compiler/browser corpus first, with account-specific token limits and no permissive validation changes. <https://console.groq.com/docs/rate-limits> <https://console.groq.com/docs/structured-outputs>
- Google Gemini API Free is quota-by-project and model, not a universally assured RPD number. Its free-tier data-use terms differ: some free requests may be used to improve products; don't route private customer prompts without verified terms, disclosures and user choice. <https://ai.google.dev/gemini-api/docs/rate-limits> <https://ai.google.dev/gemini-api/docs/pricing>
- OpenRouter Free currently lists 50 requests/day, limited uptime/support, not an SLA. Hugging Face free monthly Inference Providers credit is only $0.10. Neither can silently replace first-party generation. <https://openrouter.ai/pricing> <https://huggingface.co/docs/inference-providers/pricing>
- Cloudflare AI Gateway response caching uses exact identical request bodies unless explicitly configured otherwise. It is **not** a semantic cache of arbitrary private prompts. Do not cache per-user plaintext or serve another account's private work. <https://developers.cloudflare.com/ai-gateway/features/caching/>
- Cloudflare Workers AI prefix caching benefits supported models sharing a static prefix and reduces prefill cost; qualification must check cached token usage and supported model in real receipts. <https://developers.cloudflare.com/workers-ai/features/prompt-caching/>

### Engineering sequence
A. Preserve signed/E2EE and global quota hard bounds. Measure p50/p95 actual token/neuron usage across all qualifying app classes. The 924 reservation is a worst-case bound; refunding unused reserve already permits far more than eight average-size jobs in principle.
B. Reduce unnecessary request input: static-first shared prompts, shorter schema/IR where semantically identical, re-use local compiler error messages for deterministic fixes; compare exact five-case native/compiler/browser corpus BEFORE reducing token ceilings.
C. Qualify optional smaller-request provider behind explicitly gated access and independent provider quotas; do not silently switch providers for a dispatched job or replay uncertain inferences.
D. When real paid demand justifies predictable capacity, use an approved small Cloudflare Workers Paid budget with spend alerts and an account-wide application cost ceiling. Change paid admission only after the provider plan is active and merchant fulfillment tests pass; never surprise-charge the operator.

## Infrastructure choices
Render Free's documented limitations: spins down after 15 minutes idle, starts may take ~1 minute, ephemeral filesystem, 750 shared instance hours/month, limited resources and no production SLA. Keeping the service warm may reduce normal idle latency but doesn't remove suspension, failures or resource limits. Render explicitly discourages Free instances for production. <https://render.com/docs/free>
No pure-software fix can guarantee zero cold starts AND zero billed compute AND public-scale availability. Production choice: accept clearly limited pilot, or fund a modest managed instance/VPS and establish backups/alerts. Moving the Rust/Next/Caddy stack to Cloudflare Workers is a substantial redesign, not a one-line migration.

## Nonnegotiable controls
Never reset/spoof quota ledgers, split traffic between throwaway free accounts, bypass user-side signer review, disable cert verification, retain unencrypted secrets in build/public files, ship fallback with lower compiler validation, report a sandbox refund as a real completed refund, or use unapproved auto-renewal.
